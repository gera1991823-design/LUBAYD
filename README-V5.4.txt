APP LUBAYD V5.4 - MOBILE PRO

Objetivo
- Corregir escala y jerarquia visual en iPhone y Android.
- Reducir iconos sobredimensionados.
- Evitar cortes de texto en el flujo de Servicio.
- Hacer mas compactos Inicio, Tanque, Descanso y Servicio.
- Mantener intacta la logica Firebase, roles, sincronizacion y datos.

Archivos modificados
- index.html: version 5.4.0 y cache busting.
- styles.css: bloque final MOBILE PRO.
- service-worker.js: cache 5.4.0.
- manifest.webmanifest: version de recursos actualizada.
- reset.html: actualizacion 5.4.
- app.js: se incluye sin cambios funcionales para reemplazo seguro.

Instalacion
1. Reemplazar los seis archivos del ZIP en la raiz del repositorio.
2. Confirmar el commit.
3. Esperar la publicacion de GitHub Pages.
4. Abrir /reset.html y pulsar Actualizar y abrir aplicacion.
5. Confirmar Version 5.4.0.

No se modifican reglas de Firestore ni Storage.
