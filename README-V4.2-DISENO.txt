# APP LUBAYD V4.2 — Diseño verde empresarial

Esta actualización reproduce el diseño aprobado para escritorio y celular:

- barra lateral verde oscura con logo original;
- iconos SVG modernos y empresariales;
- indicadores de jornadas, servicios, combustible y horas operadas;
- resumen visual del tanque principal;
- flujo de combustible del día;
- actividad reciente y accesos rápidos;
- cabecera y navegación inferior verde en celular;
- mantiene Firebase, roles, chat, reportes, trabajo offline y sincronización.

## Archivos a reemplazar

- `index.html`
- `styles.css`
- `app.js`
- `service-worker.js`
- `manifest.webmanifest`
- `reset.html`

No es necesario cambiar las reglas de Firestore ni Storage.

Después de publicar en GitHub Pages, abrir:

`https://gera1991823-design.github.io/LUBAYD/reset.html`

Seleccionar **Actualizar y abrir aplicación**.
